## Frequently Asked Questions

[Contact Us](https://poolproof.com/get-in-touch/)

How are issues different from work orders?

Issues track problems. Work orders track solutions. An issue is “customer’s pump is making noise.” A work order is “replace pump motor at 123 Main St on Tuesday.” Issues often lead to work orders, and PoolProof connects them for full traceability.

Can customers create issues directly?

Customers don’t log into the system, but they can report problems via text (SMS), WhatsApp, or email. These messages come into your inbox where AI can automatically create issues, or staff can create issues from the conversation.

How does AI issue creation work?

When a customer messages about a problem, AI analyzes the message to detect the issue type and urgency. It then asks follow-up questions to gather details such as “Can you describe the noise?” or “Is the pool still usable?” Based on responses, it creates a fully categorized issue with an auto-generated summary.

Can I create a work order from an issue?

Yes. One click creates a work order from an issue, transferring customer and address information automatically. The work order links back to the issue so you can track the complete resolution path.

How do issues connect to customers?

Every issue is linked to a customer and service address. When viewing an issue, you see the customer’s full profile, service history, and any other open issues. When viewing a customer, you see all their issues.
